Media & Documents

Every <video>, <audio>, embedded YouTube / Vimeo / Wistia player, and linked PDF / Excel / Word / PowerPoint detected on the scanned pages. Captions, audio-description, autoplay, accessible name, link-purpose, file-type and size hints are validated automatically. Each linked document is also flagged as requiring a manual audit of its own content (tagging, alt text, table headers, reading order) — a web crawler cannot audit the file itself.
