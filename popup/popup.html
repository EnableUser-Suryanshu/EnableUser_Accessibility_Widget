EnableUser: Smart Accessibility Testing for Your Application

Scan Current Page
Only the current page will be scanned
Multi Page Scan
Crawls same-site links + sitemap.xml / robots.txt. Opens the tabbed audit report (findings, screenshots, templates); the classic table report is one click away from there.
Inventory / Scope Mode
Full audit + component inventory + static/dynamic classification per page. Produces scope.docx + inventory.xlsx. Screenshots only if enabled below. Depth is unbounded by default (only Max URLs caps the crawl).
Workflow Analyzer (record as you browse)
Start recording, then browse the journey — log in, fill the form, check out. Every page load and page change is scanned automatically; repeated issues are counted once. Stop to get the timeline report.
Template Check (paste URL list)
Skip discovery. Visit each pasted URL, compute its template fingerprint, and cluster the list so you can see which URLs share a shell (uniform) vs. which are distinct (varied). Every pasted URL appears as its own row — no dedup collapse.
Checks to run (mix & match — run any subset)
Annotate This Page
Marks every confirmed violation on the page in front of you — numbered, with the offending code and the fix axe recommends. Needs-review findings are excluded. Nothing is saved and no report is opened.
